# Контур-60

Сложная минутная головоломка в стиле аварийного тактического терминала.

## Цель

Поверните элементы сети 6×6 и подайте энергию от источника ко всем пяти терминалам за 60 секунд. Заблокированные узлы уже установлены правильно. Если время закончится, контур отключится.

## Управление

- `WASD` / стрелки — выбрать узел.
- `E` / `Пробел` — повернуть по часовой стрелке.
- `Q` — повернуть против часовой стрелки.
- ЛКМ / ПКМ — выбрать и повернуть узел.
- `P` / `Esc` — пауза.
- `Enter` — начать или повторить попытку.

## Локальный запуск

Требуется Node.js 18 или новее.

```bash
npm start
```

Откройте `http://127.0.0.1:4173`.

## Проверка и сборка

```bash
npm test
npm run lint
npm run build
```

Готовая статическая версия создаётся в каталоге `dist/`.
