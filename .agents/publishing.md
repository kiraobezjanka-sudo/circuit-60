# Git и публикация

- Проект является самостоятельной игрой; не переносить в репозитории других игр.
- Рабочие ветки именуются `codex/*`; изменения игры не отправляются напрямую в `main`.
- Репозиторий: `kiraobezjanka-sudo/circuit-60`.
- Текущий Pull Request: `codex/circuit-60` → `main`, PR №1.
- Временное превью PR: `https://kiraobezjanka-sudo.github.io/circuit-60/pr-preview/pr-1/`.
- Сборка превью публикуется из `dist/` в `gh-pages/pr-preview/pr-<номер>/` и при закрытии удаляет только собственный каталог.
- Перед каждым обновлением GitHub пользователь лично проверяет локальную версию и отдельно разрешает передачу именно этой версии.
- Не сливать Pull Request и не публиковать production без явного разрешения пользователя.
- После разрешённого слияния проверить корневой GitHub Pages URL, заменить временную ссылку в README и настроить тот же постоянный URL в About.
