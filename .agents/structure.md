# Технологии и структура

Игра построена на HTML, CSS и JavaScript без сторонних runtime-зависимостей. Пространственное поле рисуется в Canvas, а HUD, кнопки и оверлеи остаются DOM-элементами.

- `index.html` — единственная страница и семантическая структура интерфейса.
- `src/game.js` — авторитетная модель состояния и игровые правила.
- `src/app.js` — ввод, Canvas-рендер, HUD, таймер анимации и необязательный звук.
- `src/styles.css` — визуальная система и адаптивная компоновка.
- `test/` — детерминированные проверки правил.
- `scripts/build.mjs` — статическая сборка в `dist/`.
- `scripts/serve.mjs` — локальный HTTP-сервер.
- `.agents/` — разделённые канонические инструкции проекта; корневой `AGENTS.md` служит только индексом.
