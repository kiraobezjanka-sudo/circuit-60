# Проверка

## Команды

- `npm test`
- `npm run lint`
- `npm run build`
- `npm start`

## Браузерные сценарии

Проверять старт, клавиатуру, мышь, паузу и продолжение, победу, поражение по таймеру, перезапуск, изменение размера, широкий и узкий экран, загрузку всех ресурсов и отсутствие ошибок в консоли.

Только на localhost параметры `?seed=<число>&duration=<мс>` разрешают воспроизводимую и ускоренную браузерную проверку. Без этих параметров длительность попытки всегда составляет 60 секунд.
