# Контур-60

## Концепция и объём

Одиночная браузерная ПК-головоломка: оператор за 60 секунд восстанавливает сеть 6×6, поворачивая узлы. Игра автономна, использует оригинальную тактическую техно-стилистику и не требует внешних сервисов.

## Правила, которые нельзя нарушать

- Победа наступает только при одновременном питании пяти терминалов.
- Поражение наступает при достижении таймером нуля.
- Новая схема всегда строится из связного решаемого дерева и перемешивается.
- Заблокированные узлы не вращаются и уже стоят правильно.
- Состояния: `idle`, `running`, `paused`, `won`, `lost`.
- Пауза сохраняет остаток времени; ввод во время паузы и после завершения не меняет схему.
- Базовая длительность попытки — 60 000 мс, поле — 6×6.

## Управление и доступность

- `WASD` и стрелки выбирают узел по физическим кодам клавиш.
- `E`/`Пробел` вращают по часовой стрелке, `Q` — против.
- ЛКМ вращает по часовой, ПКМ — против.
- `P`/`Esc` управляют паузой, `Enter` запускает и перезапускает игру.
- Интерфейс сохраняет работоспособность на узком экране и учитывает `prefers-reduced-motion`.

## Технологии и структура

- `src/game.js` — авторитетная модель и правила.
- `src/app.js` — ввод, Canvas-рендер, HUD и звук.
- `src/styles.css` — адаптивная визуальная система.
- `test/` — детерминированные проверки правил.
- `scripts/` — локальный сервер и статическая сборка в `dist/`.

## Проверка

- `npm test`
- `npm run lint`
- `npm run build`
- `npm start`
- В браузере проверить старт, мышь, клавиатуру, паузу, победу, поражение, перезапуск, широкий и узкий экран, консоль.
- Только на localhost параметры `?seed=<число>&duration=<мс>` разрешают воспроизводимую и ускоренную браузерную проверку; без них длительность всегда 60 секунд.
